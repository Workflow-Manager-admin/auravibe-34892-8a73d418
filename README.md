# My AuraGram Monorepo

This repository contains the full-stack codebase for **My AuraGram**—a modern, Instagram-inspired social media platform.

## Structure

```plaintext
/
  README.md
  frontend/   # React + Tailwind (Times New Roman, black/white UI)
  backend/    # Node.js + Express + MongoDB server API
  common/     # Shared types, utils, or configs (if needed)
```

## Tech Stack

- **Frontend:** React.js (with Vite), Tailwind CSS, Times New Roman font, enforced black/white theming
- **Backend:** Node.js, Express.js, MongoDB (Mongoose)
- **Database:** MongoDB Atlas (cloud-hosted, supports easy auth integrations)
- **Media Storage:** (Plan) Cloudinary, optional: Firebase Storage
- **Shared:** (Plan) Common JavaScript/TypeScript utility functions, types, or configs across client/server

## Features Outline

- User Authentication (email/Google)
- Profile Management, Media Uploads
- Feed, Post Interactions (like, comment, save)
- Follow System, Real-time Notifications
- Explore Page, Stories, DMs, Admin Dashboard
- Dark/light mode toggle, full mobile responsiveness
- ...and much more

## Getting Started

Each package (frontend, backend) contains its own README with setup instructions.

## Project Setup

- Install dependencies in both `frontend/` and `backend/`
- Configure environment variables as needed
