# My AuraGram Frontend

This is the React + Tailwind frontend for My AuraGram.

## Setup

```sh
cd frontend
npm install
npm run dev
```

## Features

- React (with Vite)
- Tailwind CSS with Times New Roman font and a globally enforced black/white theme
- Responsive, vibey UI
- Structured for integration with backend

## Tech Decisions

- Vite for instant HMR and modern build tooling
- Tailwind for utility-first, consistent styling
- Times New Roman font, black background, and white fonts globally
